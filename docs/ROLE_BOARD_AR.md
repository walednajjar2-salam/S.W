# لوحات KPI حسب الدور + تنبيهات استباقية (v54)

## ماذا يفعل؟
- يعرض **لوحة دورك اليوم** أعلى لوحة التحكم
- يفلتر التنبيهات حسب الدور (محاسب / عمليات / صيانة / مالك…)
- يظهر أهم 3 أولويات تحتاج إجراء
- يحدّث جرس التنبيهات بعدّاد حيّ عبر البث المباشر

## أين تجده؟
- لوحة التحكم → بطاقة «لوحة دورك»
- القائمة → **التنبيهات**

## واجهة API
- `GET /api/role_board`
- `GET /api/alert_center` (مفلتر بالدور)

## الأدوار
| الدور | التركيز |
|------|---------|
| owner / admin | الكل + الاعتمادات |
| accountant | مالية · تحصيل · بنك · اعتمادات |
| operations | عقود · إشغال · صيانة |
| maintenance | صيانة عاجلة · مخزون |
