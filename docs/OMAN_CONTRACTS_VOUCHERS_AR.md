# عقود البيع والشراء والفواتير وسندات الصرف (عُمان)

تصميم المستندات مطابق لهوية موقع **النجار والسموم** (ذهبي / أسود / شعار الشركة).

## المستندات

| المستند | المصدر | الزر |
|---------|--------|------|
| عقد بيع مركبة | المبيعات | عقد بيع |
| فاتورة بيع | المبيعات | فاتورة |
| سند قبض | المبيعات | سند قبض |
| عقد شراء مركبة | المشتريات | عقد شراء |
| فاتورة شراء | المشتريات | فاتورة |
| سند صرف (شراء) | المشتريات | سند صرف |
| سند صرف (مصروف) | المصاريف | سند صرف |

## الاستخدام

1. ادخل لوحة الموظفين: `/auto-trading.html`
2. سجّل بيعاً أو شراءً أو مصروفاً
3. من الجدول اطبع المستند المطلوب (PDF عبر نافذة الطباعة)

## بيانات المركبة على العقد

عقد البيع أو الشراء يعرّف المركبة برقم الهيكل ورقم المحرك ورقم اللوحة، لذلك
تُرفق هذه الحقول مع كل عملية بيع وشراء — سواء طُبع المستند مباشرة بعد التسجيل
أو أُعيدت طباعته لاحقاً من الجدول.

## المبلغ كتابةً

السندات والعقود تكتب المبلغ بالحروف كما يقتضي العمل في عُمان، مثل:

> **1,500.000 ر.ع** — فقط ألف وخمسمئة ريال عماني لا غير

المبالغ تُعرض بثلاث خانات عشرية لأن الريال يقسم إلى 1000 بيسة. صيغة المعدود
تتبع آخر رقمين: «ثلاثة ريالات عمانية» و«أحد عشر ريالاً عمانياً» و«ألف ريال عماني».

## الضريبة على فاتورة البيع

الفاتورة تصدر باسم **فاتورة بيع / Sales Invoice** بدون سطر ضريبة. عند إضافة
الرقم الضريبي إلى ملف الشركة (`vat_no` في `COMPANY_PROFILE`) تتحول إلى
**فاتورة ضريبية / Tax Invoice**، وتُفصل الضريبة من السعر المتفق عليه بنسبة
`vat_rate` (5% افتراضياً). كذلك يظهر رقم السجل التجاري (`cr_no`) على المستند
عند تعبئته.
